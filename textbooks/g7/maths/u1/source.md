### Definition 1.1

**Set** is a collection of well-defined objects.

- The individual objects in a set are called **members** or **elements** of the set.
- The braces "{ }" are used to enclose the members of the set.
- Each elements of a set separated by comma are listed between a pair of braces { } without repetition and without concern about the order of their appearance.
- We use capital letters like A, B, C, etc to denote sets. Small case letters are used to denote elements of the set. For example, the set of all vowels in English alphabet can be represented by a single letter A and described as
  A = {a, e, i, o, u}
- If a is a member of set A, then we write a ∈ A ( read as a is an element of set A).
- If a is not a member of set A, then we write a ∉ A ( read as a is not an element of set A).

### Example 1

If N = {2,4,6,8,10}, then which of the following are true and which of them are false.

a. 6 ∈ N  b. 12 ∉ N  c. 3 ∈ N  d. 2 ∉ N

**Solution:**

a. True, because 6 is found in the set N.
b. True, because 12 is not found in set N.
c. False, because 3 is not an element of set N.
d. False, because 2 is an element of set N.

### A. Equal sets

### Definition 1.2

Two non-empty sets A and B are said to be equal, if they have exactly the same elements and write, A = B.

### Example 1

**Solution:** A and B have exactly the same elements, so A = B

Two sets A and B are said to be equivalent, written A ↔ B, if and only if they have equal number of elements.

### C. Subsets

### Definition 1.4

A set A is said to be a subset of set B if every element of A is also an element of B, and write, A ⊆ B

### Example 7

**Solution:** every element of A is an element of B. so, A ⊆ B

[added step: 2 ∈ B, 3 ∈ B, 5 ∈ B.]

### Example 8

Let A = {a, c, e} and B = {a, e, i, o, u}. Is A subset of B?

**Solution:** there is an element in A which is not B, for example c ∈ A, but c ∉ B.therefore A is not subset B (i.e. A ⊄ B).

### Example 9

let M = { } and N = {a, d}, then which of the following is true?

a. M ⊆ N  b. N ⊆ N

**Solution:** a. { } contains no element at all, so there is no element of { } which is not contained in N, hence M ⊆ N is true.

b. All elements in N are also in N, hence N ⊆ N

### Note

1. Empty set is a subset of any set (i.e. for any set A, { } ⊆ A).
2. Any set is a subset of itself (i.e. for any set A, A ⊆ A).

### Exercise 1.2.1

1. State whether each of the following statements is true or false.

a. {1,4,3} ⊆ {3,4,1}

**Answer:** True
**Why:** Every element of {1,4,3} (1, 4 and 3) is in {3,4,1}, so {1,4,3} ⊆ {3,4,1}. (The sets are in fact equal, and any set is a subset of itself.)

b. {2,6,8} ⊆ {6,8}

**Answer:** False
**Why:** 2 ∈ {2,6,8} but 2 ∉ {6,8}, so not every element of the first set is in the second.

c. {2, a, 4} = {a, 2, 4}

**Answer:** True
**Why:** Both sets contain exactly the elements 2, a and 4; only the order differs, and order does not matter (Definition 1.2).

d. {a, b, c} ⊂ {c, a, b}

**Answer:** False
**Why:** {a, b, c} = {c, a, b} (same elements). A set is not a proper subset of itself (Note 2, p.6), since {c, a, b} has no element that is not in {a, b, c}.

e. {7,4} ⊂ {7,4,5,6}

**Answer:** True
**Why:** 7 and 4 are both in {7,4,5,6}, so {7,4} ⊆ {7,4,5,6}; and {7,4,5,6} has extra elements (5 and 6), so the subset is proper.

f. {5,7,9} ↔ {x, y, z}

**Answer:** True
**Why:** {5,7,9} has 3 elements and {x, y, z} has 3 elements; 3 = 3, so the sets are equivalent (Definition 1.3).

g. { } ⊂ {3,4}

**Answer:** True
**Why:** The empty set is a proper subset of any set other than the empty set (Note 1, p.6), and {3,4} is not empty.

h. ∅ ⊆ {2}

**Answer:** True
**Why:** The empty set is a subset of any set (Note 1, p.6).

i. {m, a, c} = {a, m, d}

**Answer:** False
**Why:** c ∈ {m, a, c} but c ∉ {a, m, d} (and d is in the second set but not the first), so the sets do not have exactly the same elements.

### Summary for unit one

- **Set** is a collection of well-defined objects.
- The individual objects in a set are called **members** or **elements** of the set.
- A set which do not have an element is called **empty set**.
- Two sets A and B are said to be equal, if they have exactly the same elements.
- A set A is said to be a **subset** of set B, written A ⊆ B if every element of A is also an element of B.
- A set A is said to be a **proper subset** of set B, written A ⊂ B, if and only if A is a subset of B and B has at least one more element.
- the **union** of two sets A and B, denoted by A ∪ B, is the set of all elements which belong to A or B or both.
- The intersection of two sets A and B, denoted by A ∩ B , is the set of all elements which belongs to both A and B.

### Review Exercise for unit 1

**I. State whether the following is true or false.**

a. All equivalent sets are equal sets.

**Answer:** False
**Why:** Note on p.5: "All equal sets are equivalent, but all equivalent sets are not equal sets." For example, {1,2,3} ↔ {x, y, z} (both have 3 elements), but they do not have the same elements.

b. A set is a subset of itself.

**Answer:** True
**Why:** Note 2 on p.6: "Any set is a subset of itself (i.e. for any set A, A ⊆ A)."

c. {m, n, o} ⊆ {m, n}

**Answer:** False
**Why:** o ∈ {m, n, o} but o ∉ {m, n}, so not every element of the first set is in the second.

d. 2 ∈ {0,4,12}

**Answer:** False
**Why:** The elements of the set are 0, 4 and 12; 2 is not listed, so 2 ∉ {0,4,12}.

**II. Choose the correct answer**

1. Which one of the following is **not** a proper subset of the set {e, f}?
   A. { }  B. {e}  C. {f}  D. {e, f}

**Answer:** D
**Why:** All subsets of {e, f}: { }, {e}, {f}, {e, f}.
{ }, {e}, {f} are proper subsets (each is a subset and {e, f} has an extra element).
{e, f} is the set itself, and a set is not a proper subset of itself (Note 2, p.6).

2. Which one of the following is equivalent to the set {a, 3}?
   A. { }  B. {2,3}  C. {a}  D. {3}

**Answer:** B
**Why:** {a, 3} has 2 elements.
A. { } has 0; B. {2,3} has 2; C. {a} has 1; D. {3} has 1.
Only {2,3} has the same number of elements (2), so {2,3} ↔ {a, 3}.

3. If A ⊆ B, then which one of the following is necessarily true?
   A. A ∩ B = B  B. A ∩ B = A  C. A ∪ B = A  D. A ⊂ B

**Answer:** B
**Why:** A ⊆ B means every element of A is in B, so the elements in both A and B are exactly the elements of A: A ∩ B = A.
A and C are only true when A = B. D is not necessarily true, because A could equal B (then A ⊆ B but A ⊄ B).

4. If A = {a, b}, B = {c, d},then A ∩ B is equal to:
   A. { }  B. {a, b, c, d}  C. {c, d}  D. {d}

**Answer:** A
**Why:** a ∉ B and b ∉ B, so A and B have no common element; A ∩ B = { }. ({a, b, c, d} is A ∪ B, not A ∩ B.)
