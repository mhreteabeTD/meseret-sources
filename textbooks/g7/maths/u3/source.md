## Unit 3 Linear equations

### Learning Outcomes

At the end of this unit, you should be able to:

- identify variables, terms and variables in algebraic expressions
- simplify algebraic expressions
- develop their skills on rearranging and solving linear equations.
- apply the rules of transformation of linear equations for solving problems
- draw a line through the origin whose equation is given.
- apply real-life situations in solving linear equations

[review: the first outcome reads "identify variables, terms and variables" as printed — "variables" is repeated; probably meant "variables, terms and expressions".]

### Introduction

In this unit you will learn the importance of variables in mathematics, apply variables in solving linear equation, like linear equation with one variable involving brackets and linear equation involving fractions.

The unit has four sections. The first section deals with the use of variables in formula and the second section deals with solving linear equation, the third section deals with cartesian coordinate system and the last section deals about application of linear equations. Here the student will see how to use variables in formula and how to solve linear equation with one variable involving brackets and fractions.

#### Activity 3.1.1

1. Identify the variables
   23, x, 4, y, z, 0.5, 3x, 3/4, a, 3b, 1/2

A variable is a letter or symbol standing for an unknown number (Definition 3.1, p.58).
x, y, z, a are letters → variables.
3x = 3 × x → contains the variable x.
3b = 3 × b → contains the variable b.
23, 4, 0.5, 3/4, 1/2 are fixed numbers (constants) → not variables.

y − 5

### 3.1.2 Variables, Terms and Expressions

#### Activity 3.1.2

1. Which of the following are terms and which are not terms?
   a. x + y  b. 2x + 3  c. 2x  d. −3x  e. 3/y  f. 4

**Answer:** Terms: c. 2x, d. −3x, e. 3/y, f. 4. Not terms: a. x + y, b. 2x + 3.
**Why:** 
A term is a constant, a variable, or a product or quotient of a number and variable (Definition 3.2, p.60).
a. x + y is two terms joined by "+" → not a term.
b. 2x + 3 is two terms joined by "+" → not a term.
c. 2x is a product of a number and a variable → term.
d. −3x is a product of a number and a variable → term.
e. 3/y is a quotient of a number and a variable → term.
f. 4 is a constant → term.

2. Find the numerical coefficient of the following terms.
   a. −3x  b. y  c. −xy²  d. xy/4

**Answer:** a. −3  b. 1  c. −1  d. 1/4
**Why:** 
The numerical coefficient is the number factor of the term (Definition 3.3, p.60).
a. −3x = (−3) × x → −3
b. y = 1 × y → 1
c. −xy² = (−1) × xy² → −1
d. xy/4 = (1/4) × xy → 1/4

3. Identify whether each pair of the following are like terms or unlike terms?
   a. 5x² and 3y²  b. 3x and x  c. 2xy and yx  d. 8x²y and 4xy²

**Answer:** a. unlike  b. like  c. like  d. unlike
**Why:** 
Like terms have exactly the same variables with the same exponents (Definition 3.4, p.61).
a. 5x² has variable x; 3y² has variable y → different variables → unlike.
b. 3x and x both have x¹ → like.
c. 2xy and yx: yx = xy (order of multiplication does not matter) → like.
d. 8x²y has x², y¹; 4xy² has x¹, y² → exponents differ → unlike.

#### Definition 3.2

A constant (a number), a variable, product or quotient of a number and variable is called a term.

#### Example 1

- 4 is a term.
- xy is a term.
- 12xy − 4 is not a term.
- 3x/y is a term.
- x − y is not a term.

#### Definition 3.3

In the product of a number and variable, the numerical factor of the term is called numerical coefficient.

#### Example 2

a. The numerical coefficient of 6ab is 6.
b. The numerical coefficient of −3xy is −3.
c. The numerical coefficient of x is 1.
d. The numerical coefficient of −2ab/3 is −2/3.

(p.61)

#### Definition 3.4

Like terms are terms whose variable and exponent of variable are exactly the same but they may differ in their numerical coefficients. Terms which are not like terms are called unlike terms.

A term which do not contain a variable is called constant term. All constant terms are like terms.

[Figure (boxed note): "3x is the same as 3x¹" with an arrow from a box labelled "Exponent" pointing to the 1 in 3x¹; below it "5x²" with an arrow from a second box labelled "Exponent" pointing to the 2.]

#### Example 3

- 2 and −5 are like terms, because they are constant terms.
- (3/5)a²b² and −(2/3)b²a² are like terms.
- −20abc and acb are like terms.
- 3xyz and x²y²z² are unlike terms.
- −2a³b³c³ and −2a³b²c³ are unlike terms.
- 3xy and 3yx are like terms.

#### Definition 3.5

Algebraic expressions are formed by using numbers, letters and the operation of addition, subtraction, multiplication and division.

#### Example 4

12, 2x − 3, a + 10, 3x, (3/4)a, 3x, 3x + 2a − 5, etc. are algebraic expressions.

#### Note

The terms of an algebraic expression are parts of the expression that are connected by plus or minus signs.

#### Example 5

In the expression 3x + 2a − 5, the terms are 3x, 2a and −5. And the constant term is −5.

#### Definition 3.6

An algebraic expression in algebra which contains one term is called a monomial.

#### Example 6

5x, 12ab, 3xyz, 0.2ab … are monomials.

#### Definition 3.7

An algebraic expression in algebra which contains two terms is called a binomial.

#### Example 7

5x + 3y, 12 − ab, 3x + yz, x − b … are binomials.

#### Definition 3.8

An algebraic expression in algebra which contains three terms is called a trinomial.

#### Example 8

2x + 3y − 3, 12 + a − b, x − y − z, ab + 6 + z are trinomials.

#### Simplifying Algebraic Expressions

To simplify any algebraic expression, follow the following basic steps

- Remove brackets using distributive property.
- collecting like terms and
- add or subtract like terms.

(p.63)

#### Note

1. When you add or subtract like terms, add or subtract their numerical coefficients.
   Example: −3x + 5x = (−3 + 5)x = 2x
2. Unlike terms cannot be added or subtracted
   Example: 5x + 2y cannot be added.
3. When you remove brackets using distributive property be careful of signs.
   Example:
   a. −2(x − 4) = −2x − (−2) × 4 = −2x + 8
   b. −3(−2x − 1) = −3(−2x) − (−3)(1) = 6x + 3
4. When you multiply a number with variable, you can write the number as coefficient without multiplication sign
   Example:
   a. 4 × y = 4y
   b. 5 × (3y) = 15y

[Side box: a(b + c) = ab + ac]

#### Definition 3.9

Two different algebraic expressions connected by equal (=) sign is called equation.

#### Definition 3.10

A Linear equation in one variable x is an equation which can be written in standard form ax + b = 0, where a and b are constant numbers with a ≠ 0.

#### Note

an equation of a single variable in which the highest exponent of the variable is one is a linear equation.

#### Rules of transforming equations to simpler form

Consider the following balances,

**Rule 1:** Adding the same number to both sides of equation will not affect the equation.

[Figure d: a balanced see-saw with "10kg" on each pan; text "dividing both sides by 2"; then a balanced see-saw with "5kg" on each pan.]

If a = b, then a/c = b/c, where a, b, and c are any constant number and c ≠ 0

#### Solving equations containing variable on both sides of the equation

Consider the equation x − 5 = 10, in solving this equation you add 5 on both sides and get x = 10 + 5, this is the same as shifting −5 to the other side of the equation and it becomes +5. i.e.

#### Note

In solving equation containing variable on both sides, collect the terms containing variables on one side and numbers on the other side and do not forget changing the signs when you shift a term from one side to the other.

#### Locating points on the coordinate plane

- Points on Cartesian plane is described by two numbers (a, b) that are called coordinates.
- The first number a, is the horizontal position of the point from the origin. It is called x − coordinate (abscissa).

(p.80)

- The second number b is the vertical position of the point from the origin. It is called y − coordinate (ordinate).

To locate a point (a, b) on a coordinate plane follow the following steps.

Step 1: Move a unit in the horizontal direction from the origin.

- Move a unit to the right if a is positive.
- Move a unit to the left if a is negative.

Step 2: Then, move b unit in the vertical direction

- Move b unit up if b is positive.
- Move b unit down if b is negative.

### Summary for unit 3

- A variable is any letter or a symbol that represent some unknown number or value.
- a constant (a number), a variable, product or quotient of a number and variable is called a term.
- In the product of a number and variable, the numerical factor of the term is called numerical coefficient.
- like terms are terms whose variable and exponent of variable are exactly the same but they may differ in their numerical coefficients. Terms which are not like terms are called unlike terms.
- Algebraic expressions are formed by using numbers, letters and the operation of addition, subtraction, multiplication and division.
- Two different algebraic expressions connected by equal (=) sign is called equation.
- A Linear equation in one variable x is an equation which can be written in standard form ax + b = 0, where a and b are constant numbers with a ≠ 0.
- To transform linear equations to simpler form, you can apply the following rules.
  - i. if a = b, then a + c = b + c, where a, b, and c are any constant numbers.
  - ii. if a = b, then a − c = b − c, where a, b, and c are any constant numbers.
  - iii. If a = b, then a × c = b × c, where a, b and c are any constant number and c ≠ 0.
  - iv. If a = b, then a/c = b/c, where a, b and c any constant number and c ≠ 0.

(p.100)

- To solve linear equations involving brackets, remember the following key properties. For any numbers a, b and c
  - a + (b + c) = a + b + c
  - a − (b + c) = a − b − c
  - a − (b − c) = a − b + c
  - a(b + c) = ab + ac
  - a(b − c) = ab − ac

  [review: the book prints a capital "C" inside the brackets in the first three identities ("a + (b + C)", "a − (b + C)", "a − (b − C)"); it is the same variable c]
- Points on cartesian plane is described by two numbers (a, b) that are called coordinates.
  - i. The first number a, is the horizontal position of the point from the origin. It is called x − coordinate (abscissa).
  - ii. The second number b is the vertical position of the point from the origin. It is called y − coordinate (ordinate).
- The graph of the equation of the line x = a, a is constant is a line parallel to y-axis at a distance of a unit from the origin.
- The graph of the equation of the line y = b, b is constant is a line parallel to x-axis at a distance of b unit from the origin.
- The graph of y = mx passes through 1st and 3rd quadrant when m > 0
- The graph of y = mx passes through 2nd and 4th quadrant when m < 0
- In the equation of the line y = mx, m is called **slope** of a line.
- For any values of m the graph of y = mx passes through the origin.
- In solving word problems follow the following steps
  - i. Read the problem carefully
  - ii. Select variables for unknown quantities
  - iii. Write a mathematical equation
  - iv. Solve the equation
  - v. Interpret the result and write the final answer in words.
  - vi. Check the answer

(p.101)

### Review Exercise for unit 3

#### I. Write True for the correct statements and False for the incorrect statements.

**1.** For any integers a, b and c, a(b + c) = ab + ac.
**Answer:** True
**Why:** This is the distributive property listed in the Summary (p.100): a(b + c) = ab + ac.

**2.** An algebraic expression 2x² + 2xy is trinomial algebraic expression.
**Answer:** False
**Why:** 2x² + 2xy has two unlike terms (2x² and 2xy), so it is a binomial, not a trinomial (a trinomial has three terms).

**3.** 3a²b and 3ab² are like terms.
**Answer:** False
**Why:** Like terms need the same variables with exactly the same exponents (Summary, p.99). In 3a²b, a has exponent 2 and b exponent 1; in 3ab², a has exponent 1 and b exponent 2. So they are unlike terms.

**4.** If a = b, then a − b = 0.
**Answer:** True
**Why:**
a = b
Subtract b from both sides (rule ii): a − b = b − b
a − b = 0

**5.** The equation of the line x + y = 0 is vertical line.
**Answer:** False
**Why:**
x + y = 0 → y = −x, which is of the form y = mx with m = −1.
It is a slanted line through the origin passing through the 2nd and 4th quadrants. A vertical line has the form x = a.

**6.** 4 is the slope of a line y − 4x = 0.
**Answer:** True
**Why:**
y − 4x = 0
y − 4x + 4x = 0 + 4x
y = 4x → m = 4, and m is the slope.

**7.** The numerical coefficient of 3xy² is 2.
**Answer:** False
**Why:** The numerical coefficient is the number factor of the term, which is 3. The 2 is the exponent of y.

**8.** If c = d, then a + c = d + a.
**Answer:** True
**Why:**
c = d
Add a to both sides (rule i): a + c = a + d
a + d = d + a (order of addition does not matter), so a + c = d + a.
