## INTRODUCTION

What you had learnt in the previous grades about multiplication will be used in this unit to describe special products known as squares and cubes of the given numbers. For instance, in a real-life application when you want to find a new apartment, you need to know the size of it. Newspaper and online advertisements usually give the dimensions of the apartment by only listing its area, such as 625 square meters. This can be hard to you use the concepts of square roots and convert this number in the form of 25 × 25 square meters. It gives better ideas of the apartment. The following sub-topics will give a brief explanation about squares and cubes.

**Note :** There is a difference between a² and 2a.
i. a² = a × a
ii. 2a = a + a

Consider the following examples to see the difference
a. 10² = 10 × 10 = 100 *while* 10 × 2 = 20
b. (0.4)² = 0.4 × 0.4 = 0.16 *while* 0.4 × 2 = 0.8

In general, a² ≠ 2a for any rational number a.

[review: "a² ≠ 2a for any rational number a" is not true for every a: when a = 0 (0² = 0 = 2 × 0) and a = 2 (2² = 4 = 2 × 2) they are equal. The book means "in general a² and 2a are different".]

**Definition 2.2:** A rational number x is called a perfect square if and only if x = m² for some m ∈ ℚ.

**Example 2.4:**
1² = 1, 2² = 4, 3² = 9, 4² = 16, (1/5)² = 1/25, (1/6)² = 1/36. Thus, 1, 4, 9, 16, 1/25 and 1/36 are perfect squares.

**Note**
i. The square of rational numbers is also rational numbers.
ii. 0 × 0 = 0 Therefore, 0² = 0
iii. For any rational numbers a and b, (ab)² = a²b²
iv. For any rational numbers a and b, (a/b)² = a²/b² where b ≠ 0

1. Determine whether each of the following statements is true or false.

a) 10² = 10 × 10
**Answer:** True
**Why:** Squaring means multiplying a number by itself: 10² = 10 × 10 = 100.

b) 8² = 8 × 2
**Answer:** False
**Why:** 8² = 8 × 8 = 64, but 8 × 2 = 16; 64 ≠ 16 (a² ≠ 2a).

c) x² = 2x, where x ∈ ℚ
**Answer:** False
**Why:** x² = x × x while 2x = x + x. For example x = 3: 3² = 9 but 2 × 3 = 6. (They are equal only for x = 0 and x = 2, so the statement is not true for all x ∈ ℚ.)

d) −60² = 3600
**Answer:** False
**Why:** Without brackets only 60 is squared: −60² = −(60 × 60) = −3600 ≠ 3600. (Only (−60)² = (−60) × (−60) = 3600.)
[review: if the book intended (−60)² = 3600, the answer would be True; as printed (no brackets) it is False.]

**Answer:** True
**Why:** (−30)² = (−30) × (−30) = 900 (negative × negative = positive).

**Theorem 2.1:** Existence theorem
For any rational number x, there is a rational number y (y ≥ 0) such that x² = y

**Example 2.5:**
Find the square of the following rational numbers by using the existence theorem.
a) x = 12   b) x = 0.04   c) x = 1/2   d) x = −1/4

**Solution:**
a) x = 12. Then y = x² = 12² = 144
b) x = 0.04. Then y = x² = (0.04)² = 0.0016
c) x = 1/2. Then y = x² = (1/2)² = 1/4
d) x = −1/4. Then y = x² = (−1/4)² = 1/16

***How to approximate square of a number?***

Rough calculation could be carried out for approximating and checking the results in squaring rational numbers. Such approximation depends on rounding off decimal numbers. Rounding is the process to estimate (approximate) particular number in context. To round a number look at the next digit in the right place, if the digit is less than 5, round down and if the digit is 5 or more than 5, round up. Rounding decimals is useful to estimate an answer easily and quickly.

**Example 2.6:**
Find the approximate value of x² in each of the following decimals
a) x = 4.3
b) x = 0.026
c) x = 2.45

**Solution:**
a) x = 4.3 ≈ 4 [since 3 < 5]
x² = 4² = 16
Therefore, (4.3)² ≈ 16

(p.48)

b) x = 0.026 ≈ 0.03
x² = 0.03² = 0.0009
Therefore, (0.026)² ≈ 0.0009

c) x = 2.45 ≈ 2.5
x² = (2.5)² = 6.25
Therefore, (2.45)² ≈ 6.25

ii. The symbol ∛ is called a radical sign. The expression ∛a is called a radical, 3 is called the index and a is called the radicand. When no index is written, the radical sign indicates square root.
iii. The relation between cubing and cube root can be expressed as:
[Figure (diagram, unnumbered): two arrows. Top: a → box "Cubing" → a³. Bottom: a³ → box "Cube root" → a (arrow pointing back to a).]
iv. ∛a = a^(1/3) [exponential form]
v. Each rational number has exactly one cube root.

(p.61)
